PIGSTY INFRA REPO

aptdnf / yum{{ if $zh }}可升级{{ else }}upgradable{{ end }}

{{ if $zh }}pig 位于 pigsty-infra 仓库。把仓库加进系统之后，安装与后续升级都走 apt / dnf，与其它系统软件一致。{{ else }}pig lives in the pigsty-infra repository. Once the repository is wired in, installs and upgrades go through apt / dnf like any other system package.{{ end }}

shell
sudo tee /etc/apt/sources.list.d/pigsty-infra.list >/dev/null <<EOF
deb [trusted=yes] {{ $mirror }}/apt/infra generic main

sudo apt install -y pig
shell
sudo tee /etc/yum.repos.d/pigsty-infra.repo >/dev/null <<-'EOF'
[pigsty-infra]
name=Pigsty Infra for $basearch
baseurl={{ $mirror }}/yum/infra/$basearch
enabled=1
gpgcheck=0
module_hotfixes=1
EOF

sudo dnf makecache
sudo dnf install -y pig
